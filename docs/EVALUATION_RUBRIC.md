# Evaluation Rubric

## Core pedagogical dimensions

All scores use a 1–5 scale.

## 1. PCK and conceptual accuracy

Measures whether the teacher's explanation is conceptually correct, appropriately targeted, and responsive to misconceptions.

- **1**: inaccurate, misleading, or misses key misconception.
- **3**: mostly accurate but partial or generic response.
- **5**: accurate, targeted, and misconception-aware.

## 2. Scaffolding

Measures whether the teacher gives stepwise support without giving the answer too early.

- **1**: no useful guidance or gives answer directly.
- **3**: some guidance but inconsistent.
- **5**: clear stepwise support matched to student need.

## 3. Formative assessment

Measures whether the teacher checks understanding and adapts based on student answers.

- **1**: does not check understanding.
- **3**: checks sometimes but weak follow-up.
- **5**: regularly checks and adapts based on responses.

## 4. Cognitive questioning

Measures Bloom-level quality of teacher questions.

- **1**: recall-only, vague, or no meaningful questions.
- **3**: some application/analysis questions.
- **5**: prompts explanation, reasoning, transfer, or evaluation.

## 5. Missed pedagogical opportunities

Measures whether key student signals or teachable moments were identified and used.

- **1**: many important signals missed.
- **3**: some signals addressed, some missed.
- **5**: key teachable moments identified and used.

## Separate evaluator reliability labels

These are not teaching-quality scores:

- `fabricated_evidence`
- `unsupported_inference`
- `pedagogical_disagreement`
- `invalid_or_missing_evidence`

# Pixel UI Design Notes

Phase 2 will implement the UI. Phase 1 only records the intended visual direction.

## Visual style

- 2D pixel classroom;
- square cards;
- 2px/4px borders;
- blocky shadows;
- high contrast;
- minimal animation;
- CSS/SVG avatars first, no complex sprite sheets in MVP.
